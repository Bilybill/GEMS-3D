Geological Multiphysics Earth Simulation

GEMS-3D

A 3D synthetic geoscience benchmark for aligned geological models and gravity, magnetic, magnetotelluric, and seismic forward responses.

Read README View Structure

Dataset

Aligned 3D models and four forward modalities

Property Volumes

Each generated sample stores aligned `vp`, `rho`, `res`, and `chi` volumes with anomaly labels and source metadata.

Geological Targets

Registry presets cover igneous intrusions, salt domes, brine faults, sulfides, hydrates, gas systems, basement interfaces, and alteration zones.

Forward Bundles

Responses are packed into `forward_bundle.npz` with observation geometry, frequency axes, acquisition settings, and method status fields.

Benchmark

Forward, inverse, and robustness tasks

Forward surrogates`rho -> gravity`, `chi -> magnetic`, `res -> MT`, `vp -> seismic`, and joint multimodal prediction.
Inverse interpretationAnomaly-family classification with single-modality and multimodal baselines.
RobustnessMissing-modality evaluation and modality-shuffled consistency controls.
